# 稳定币版 "Alipay+"：让日本钱包扫东南亚国家二维码

INSPAY 技术方案预研。问题：**如何让 PayPay 这样的日本钱包，在东南亚各国直接扫当地国家统一二维码（Thai QR / QRIS / DuitNow / SGQR / VietQR / QR Ph / KHQR / LAO QR）付款，并用稳定币替代传统跨境清结算？**

## 一页结论

1. **前台像 Alipay+**：钱包只对接一套 API（识别 → 报价 → 支付 → 通知 → 退款 → 结算单）；网络负责解析 EMVCo 国家码、识别方案、路由到当地伙伴、锁汇、风控。
2. **商户侧直接用国家码 + 国家快速支付系统**：由各国持牌参与者（银行/持牌钱包，或交换机跨境网关）把本币实时贷记到商户原有账户，商户零改造、照常收本币、用自己的银行 App 看到账。
3. **稳定币只在机构之间**：用户付日元、商户收本币。网络在新加坡枢纽持有 USDC 金库，按周期净额结算：对新加坡、菲律宾、香港的伙伴直接链上付 USDC；对泰国、马来西亚、印尼、越南等稳定币不宜入境的国家，枢纽出金后以 USD 电汇、由境内持牌银行兑换本币。链上保证金合约兜底伙伴的垫付风险。这样拿到 7×24、分钟级、可审计的好处，又不触碰多数东南亚国家"加密资产不得作为支付手段"的规定。
4. **四条接入路径**：交换机跨境网关（覆盖全国）> 单一收单行合作（只覆盖其商户码，落地快）> 借道 Alipay+/HIVEX（最快但不可控）> Nexus（2027+）。建议单国 on-us 试点起步。
5. **日本侧**：PayPay 作为為替取引主体（与其韩国/台湾海外支付同构），网络主体放在离岸（如新加坡），JPY↔稳定币在境外兑换——需律师确认。
