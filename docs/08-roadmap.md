# 08 · 分阶段路线图与验证计划

> 原则：先用最小范围把**全链路**（扫码 → 本币入账 → 稳定币结算 → 对账）跑通并留下合规记录，再扩国家、扩路径。每一阶段都列出"进入下一阶段的条件"和"最便宜的下一步验证"。

## Phase 0 · 结构与伙伴验证（约 2–3 个月）

| 工作 | 产出 | 验证方式 |
|---|---|---|
| 日本法律意见：PayPay 作为為替取引主体、网络主体离岸、JPY↔稳定币在境外兑换是否成立；2025 改正资金结算法"跨境收纳代行"是否适用 | 法律意见书 | 外部律师 |
| 新加坡法律意见：网络主体所需牌照（只与持牌机构合作 vs MPI），稳定币持有与兑换 | 法律意见书 | 外部律师 |
| PayPay BD：海外支払いモード新增网络路由的意愿、技术接口、费用分成 | 意向书/NDA + 接口对齐纪要 | 用 `docs/07-api-spec.md` 与参考实现演示 |
| 首批 LSP 候选访谈（每个目标国 2–3 家） | 合作条件对比表 | 见 05 章候选名单 |
| 稳定币枢纽：机构铸赎通道（USDC）与 1–2 家离岸 LP | 开户/KYB | — |

**进入 Phase 1 的条件**：至少 1 个目标国有签约意向的 LSP；PayPay（或另一家日本钱包/银行 App）同意做受控试点；法律意见无阻断项。

## Phase 1 · 单国试点（约 3–6 个月）

* **国家选择**：按 05 章 5.1 的评分，**建议泰国**——日本游客最多、Thai QR 普及度极高，且 PromptPay 对外只开放了中国 Alipay 走廊（Alipay+ 的其他钱包、PayPay 都进不去），差异化最强；候选伙伴 Krungsri（MUFG 集团，已与 NETSTARS/NTT DATA 合作做泰国人在日本的 MyPrompt QR）或 SCB（韩国 GLN 入境先例）。备选越南（NAPAS 已对 GLN、Liquid 等私营网络开放）；
* **路径**：B（单一收单行/钱包 on-us 合作），只付该伙伴的商户码；同时由该行作为结算行，准备 NITMX 跨境平台的"境外网络"申请材料；
* **结算**：日结 → 小时结；新加坡枢纽持有 USDC 金库，对泰国 LSP 以枢纽出金后的 USD 电汇偿付（泰方可评估 NRQC 账户），稳定币不入泰国境内；PayPay 日元 T+1 电汇至枢纽；保证金合约先上测试网、审计后上主网，索偿权可由 LSP 的离岸关联主体持有；
* **范围**：MPM、P2M、静态 + 动态码；不做 P2P；不做 CPM；
* **指标**：支付成功率、U 状态比例与平均解决时间、商户到账时延、对账差异率、每笔全链路成本（含链上费用、兑换点差、LSP 费用）、退款/争议率。

**进入 Phase 2 的条件**：试点期成功率与对账差异达到约定阈值；监管无异议；单位经济为正或有清晰路径。

## Phase 2 · 交换机级接入与多国（约 6–12 个月）

* 在试点国申请路径 A（交换机跨境网关），覆盖全部参与跨境受理的商户；
* 增加 2–3 个国家：越南（NAPAS 境外网络 + 越南结算行）、印尼（借道 BI–日本 / Netstars 框架）、柬埔寨（JPQR–KHQR 二期 + NBC 批准下的银行层稳定币结算）；新加坡、马来西亚、菲律宾已对全部 Alipay+ 钱包开放，进入时要准备好价格与结算速度上的可量化优势；
* 结算：评估日元稳定币（信托型/JPYC）作为 MPP → 网络的结算资产，实现日内结算；
* 产品：商户名查询回显、退款工具、MPP 侧 Server SDK（本地码规则下发）。

## Phase 3 · 双向与网络效应（12 个月以后）

* **入境**：东南亚钱包到日本 PayPay 商户 / JPQR 商户消费，与出境方向在同一参与者上**轧差**，大幅降低稳定币流量与浮存；
* 本币稳定币（新加坡 XSGD、泰国机构泰铢稳定币、马来西亚林吉特稳定币试点结果）作为 LSP 结算资产，实现 USDC↔本币稳定币 PvP；
* 跟踪 Nexus Global Payments（2027 年目标上线）对私营网络的开放条件。

## 竞争窗口

* **Alipay+**：PayPay 已是其钱包方（韩国出境），新、马、柬、菲、韩的国家码已对全部 Alipay+ 钱包开放——这些国家 PayPay 随时可能经 Alipay+ 开通；Ant 已有 MiCA EMT（BREUR，仅关联方批发使用）、HSBC 代币化存款、MAS BLOOM 资格，但尚未对外开放稳定币结算服务；
* **HIVEX**：软银系，已连 PayPay 双向（台湾），与 StraitsX 签 StableLink 稳定币 MOU（目标法域含日本、泰国），东南亚国家码覆盖尚弱——既是竞争者，也可能是合作对象（由本网络补齐东南亚国家码）；
* 判断：两者都可能在 12–24 个月内补上"持牌机构间稳定币结算 + 东南亚国家码"，窗口有限（判断，非事实）。

## 最便宜的下一步验证（按优先级）

1. 和 PayPay 做一次 1 小时技术对齐：用参考实现演示 identify → quote → pay → 结算单，确认其海外支払いモード能否新增一个网络路由；
2. 找一家目标国银行/钱包，确认其是否能接收"境外机构的贷记指令 + 用 USDC（或离岸 USD）偿付"，以及当地监管是否需要事前报备；
3. 让日本律师对 6.2 表格逐行给出意见；
4. 用实际报价测算全链路成本：JPY→USDC（离岸 LP 点差）+ 链上费用 + USDC→本币（在岸银行 FX）+ LSP 费用，对比 PayPay 现行 3.85% 与信用卡海外手续费。
