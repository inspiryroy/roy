# 06 · 合规结构与风险

> 本章是技术方案对法律结构的**工程化假设**，用于设计系统边界；每一条标注"需律师确认"的结论都必须在实施前取得对应司法辖区的正式法律意见。事实依据与日期见 [09-sources.md](09-sources.md)。

## 6.1 设计原则

1. **稳定币不碰终端用户与商户**：用户付日元、商户收本币；稳定币只在持牌机构之间作为结算资产。
2. **本币在境内兑换**：泰铢、林吉特、印尼盾、越南盾、基普等存在离岸交割限制的货币，只由境内持牌银行/机构兑换和入账。
3. **每段资金流都有持牌主体**：用户↔钱包（日本资金移动业者）、钱包↔网络（跨境支付/汇款）、网络↔LSP（目的国持牌参与者）、稳定币兑换（各地持牌 VASP / 稳定币发行方机构通道）。
4. **结算资产可替换**：监管变化时，同一套净额与对账流程可降级为法币电汇执行。

## 6.4 反洗钱、制裁与 Travel Rule

* **KYC 依赖**：用户 KYC 由 PayPay 完成（PayPay 海外模式要求出国前完成 eKYC）；网络对 MPP 做机构尽调，并在合同中约定 KYC 依赖与数据提供义务；
* **发起人信息**：pay 请求携带最小必要的发起人信息（姓名、居住国、钱包机构），按目的国跨境支付的信息要求（FATF R.16 及各国外汇申报）传给 LSP；
* **制裁筛查**：付款人（MPP 侧已筛）、商户名/账户（网络侧筛 + LSP 侧筛）、LSP/LP 的链上地址（链上分析工具）；
* **交易监控**：同一用户短时间多笔、同一商户账户异常的跨境收款集中、整数金额、深夜大额等规则；
* **Travel Rule**：网络 ↔ LSP / LP 的每笔稳定币转账前发送 IVMS101 信息（经 TRUST/Notabene/Sygna 等互通方案）；
* **限额复刻**：各条既有跨境 QR 线的发卡侧限额（如马来西亚出境 RM3,000/笔、香港 HK$10,000/日）作为参照，网络对每个国家/通道设置单笔、单日、单月限额，并支持 MPP 覆盖更严格的限额。

## 6.5 消费者保护与争议

* 显示：商户名 + 本地语言名 + 国家、当地币金额、日元金额、汇率与全部费用（PayPay 现行做法是"网络汇率 + 3.85%"）；
* 退款：国家快速支付系统多数没有退款报文，退款走"商户反向贷记 → LSP → 网络 → MPP"，汇率规则在 MPP 合同中写明（见 03 章 3.4）；
* 贴码诈骗：商户名查询回显、商户账户黑名单（与 LSP 共享）、新商户首笔限额、地理位置与码国家一致性校验；
* 无卡组织式 chargeback：在用户条款中明确争议处理路径与时限。
