# 东南亚商户为什么会（或不会）从静态码升级到动态码

检索日期 2026-10-18，共用 14 次 WebSearch。WebFetch 对 detik、jatimtimes、ringgitplus、tribune 都返回 DNS 失败，curl 对 vnba、mynt 被代理拒绝（403），所以本文依据 WebSearch 摘要，加上 `docs/research/*.json` 里已核实的条目。每条事实的类型（已核实 / 公司声明 / 媒体 / 推论 / 假设 / 未查到）、置信度和来源见 `pain.json`（PAIN-01～50）。标“记忆·未核实”的条目没有在线核实，使用前要先查原文。

## 一句话结论

创始人假设东南亚商户“强烈需要把静态码升级成动态码”。按本轮证据，这个假设对占商户绝大多数的贴纸小微户**不成立**。商户真正有感的痛点是**“钱到底到没到”**（假截图、假 slip、假 bill），而市场已经用更便宜的办法解决了：App 语音推送、音箱、slip 验证 API，码还是静态的。唯一有制度性拉力的是**越南的税务改革**，它要的是“收款 + 开票 + 对账一体机”，动态码只是其中一个功能。

## 1. 痛点有哪些证据

| 痛点 | 证据 | 动态码能不能解决 |
|---|---|---|
| 假付款截图 / 假 slip / 假 bill | 泰国 DES 警告有人卖假 slip 生成器，PRD 教民众识别（PAIN-13/14）；越南造假服务在社交网络公开售卖，有一名青年伪造了 300 张转账单（PAIN-19）；印尼巴图市 2026-05 商户投诉最多的仍是修图截图（PAIN-08）；马来西亚 RHB、TNG 的音箱都直接针对假收据（PAIN-25/26）；菲律宾有人卖 GCash 收据模板（PAIN-29）；新加坡一家餐馆被 35 张假 PayNow 截图骗走 S$4,620（PAIN-34） | **不需要动态码**。付款人改不了的到账确认就够了 |
| 贴纸被覆盖 | 印尼 2023-04 清真寺案：38 处，约 Rp1,306 万（PAIN-06）；新加坡只有博客提到（PAIN-35） | 能解决（屏幕上每笔现生成的码无法被覆盖），但案例集中在无人值守的捐款箱，单案损失小 |
| 冒名或欺诈商户（quishing） | GCash 封禁 4,900+ 个欺诈商户（PAIN-30） | 解决不了。问题出在商户准入（KYM） |
| 输错金额、店员私吞 | **本轮没有找到任何数据** | 能解决，但没有证据显示商户把它当痛点 |
| 手工对账 | 泰国 Ref1/Ref2、QRIS Bill No. 等字段是为自动核销设计的（PAIN-17） | 能解决，但这是有收银系统的中型以上商户的需求 |

**监管：**本轮没有找到任何一国强制商户使用动态码。BI 重心是 KYM 和 QRIS Tap（NFC），MDR 不区分静态和动态；新加坡走 SGQR+ 统一静态标签；越南央行的生物识别针对付款人（记忆）；KHQR、DuitNow 为动态码设计了过期机制，但没有强推（PAIN-10/11/12/24/36/39/46）。**数据：**八国都没有公开的静态/动态占比；印尼 4,486 万商户中 96.68% 为 UMKM，可推知静态码占绝大多数（推论）。

## 2. 分国判断

| 国家 | 商户真正感到的问题 | 现成的更便宜方案 | 会不会为动态码买单 |
|---|---|---|---|
| 越南 | 假转账 bill（极普遍）；**年营业额 ≥10 亿越南盾的个体户自 2025-06 起须用收银机电子发票，2026 年起取消定额税** | 余额变动短信和音箱（有被伪造播报的风险，低置信）；VietinBank×VNPAY、Techcombank 等的 QR+POS+发票+报税方案（VNPAY 报税方案免费到 2028 年） | **中到强**，但只限需要开票的个体户和中型店；买的是一体机，动态码是附带功能。小微户仍是弱 |
| 泰国 | 假 slip，多发生在远程或线上收款 | K SHOP 免费语音推送；SCB、Qashier 音箱（฿1,790）；SlipOK 等验证 API | 小微弱；有 POS 的餐厅和连锁中等（按单核销） |
| 印尼 | 修图截图；贴纸覆盖（规模小） | BCA、BRI、Mandiri、DANA、OVO 的音箱（多为月租），Paylabs 的 App 内播报 | 小微弱；UME/UBE 收银整合中等 |
| 马来西亚 | 假收据、假付款界面 | PayNet×RHB 音箱、TNG Soundbox、Qashier | 弱，中型商户弱到中 |
| 菲律宾 | 假 GCash 收据；冒名商户和 quishing | App 内通知和交易记录；HitPay 等音箱 | 弱 |
| 新加坡 | 假 PayNow 截图（远程订单）；贴纸覆盖（低置信） | 银行到账通知；国家推 SGQR+ 统一静态标签；熟食摊用个人 PayNow 避开企业收费 | 弱 |
| 柬埔寨 / 老挝 | 本轮没有找到证据（未检索高棉语、老挝语来源） | 不明 | 未知，推测弱到中 |

参照：印度 Paytm 设备超过 680 万台（2023），中国是收款码牌 + 云音箱。两国的小微商户都停在“静态码 + 可信播报”，没有升级到动态码。

## 3. 对 INSCREEN 的含义（推论）

1. **不要把“能出动态码”当卖点。**动态码在技术上很便宜（App 插入 tag 54 就能生成），对商户的感知价值也低。在东南亚，它主要是 INSPAY 跨境网络的需求：境外钱包要按已知金额锁汇。这是 INSPAY 自己的需求，不是商户愿意付费的需求。
2. **卖点改成“付款人改不了的到账确认 + 金额显示 + 多钱包/外国钱包受理 + 对账或开票”。**这才对得上已有的痛点。音箱可被伪造播报（越南警告，低置信）、只覆盖单一通道，这两点是 INSCREEN 可以拉开差距的地方。
3. **先切三类商户：**越南需开票的个体户（但要和银行、VNPAY 的免费方案竞争）；东南亚有收银系统、需要按单对账的中型商户和连锁；外国游客多的商户（动态码 + 锁汇对游客和商户都有价值）。
4. **小微贴纸段会遇到音箱的价格战**（约 ฿1,790，或月租）。INSCREEN 的定价和交互方式未知，本文假设它明显贵于音箱（PAIN-50）。
5. **要补的证据：**ASPI 或 NITMX 的静态/动态占比、BI PADG 原文、越南第 68/2026 号议定细则、音箱铺设量和价格，以及最关键的一项：直接访谈商户，问他们愿意为对账或开票付多少钱。目前没有找到任何“商户主动要求动态码”的证据。
